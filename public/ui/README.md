# Ilustraciones de los menús

Coloca aquí las ilustraciones con estos nombres (formato WebP). Si falta alguna, el juego usa una provisional.

| Archivo | Dónde sale | Tamaño recomendado |
|---|---|---|
| `region-kanto.webp` | Portada de la región (isla) | 1080 × 1350 (4:5) |
| `map-kanto.webp` | Mapa de Kanto (los gimnasios se colocan encima) | 1080 × 1440 (3:4) |
| `gym-brock.webp` | Cabecera del gimnasio de Brock (texto a la izquierda) | 1080 × 700 |
| `gacha.webp` | Escenario del gachapón (máquina y Pokémon) | 1080 × 900 |
| `logo.webp` | Logotipo «Pokécero» (fondo transparente) | 1000 × 360 |
